## Summary
Replace the V1 config layer in `src/plugin/mru_plugin.cpp` (`cfg_int` 43-48, `cfg_str` 50-60,
`register_config_keys` 110-126, both `#pragma GCC -Wdeprecated-declarations` pairs 40-42/62 and
107-109/128) with V2: each of 7 keys registered once in `PLUGIN_INIT` via `addConfigValueV2`,
stored as a typed `SP<Config::Values::{Int,String,Bool}>` in a new `mru::plugin::config::Values`
struct (owned by `PluginState`), read only through those stored SPs. `read_config()` keeps its
exact M2 semantics (clamp [0,5000], enum fallback+warn, ui mapping, reload-next-session-only)
and moves into new `src/plugin/config_v2.{hpp,cpp}`. Type safety = compile-time (typed SP member
is the single type table → register/read mismatch cannot compile) + catchable runtime `read()`
(null + `underlying()` match). RASSERT→SIGABRT unreachable; HIGH-4 stays belt-and-suspenders.

## Key answers
- Q-A: `Values` struct owned by PluginState (not statics); registered before build_state; cleared in teardown.
- Q-B: no `Config::Type` enum exists; typed SP member IS the type table (slot assignment compile-check) +
  `read()` template with `value_traits` runtime check that throws catchably.
- Q-C: debounce_ms→Int(i64), wrap/lock/restore→Bool(bool), default_scope/start_offset/ui→String
  (`Config::STRING` is std::string; value() by value, no ptr()). Bool stored as INT{0/1}, low-byte readback
  OK on LE; String via `typeid(const char*)`→m_hlangp branch.
- Q-D: fail closed per key via short-circuit &&; any false → PLUGIN_INIT notification + return {}.
- Q-E: no cache-invalidate; `value()` always fresh (commence() at registration; reload re-parses same slots).
- Q-F: external_socket stays unregistered until M3-S3.
- Q-G: M2 tests pass unchanged (cfg_0x tests target pure config_value fns; T-CFG-02 is domain set_policy;
  cfg_int/cfg_str/read_config/register_config_keys unreferenced by tests).
- Note: `PluginSystem::loadPluginInternal` wraps PLUGIN_INIT only in setjmp — type-contract (not setjmp)
  is the load-bearing defense for reload listeners/dispatchers.
