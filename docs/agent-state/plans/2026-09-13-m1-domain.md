## Global Constraints

- Домен чистый: **никаких Hyprland-типов** (ADR-007); namespace `mru::domain`.
- Одна активная сессия, алгоритмы в `src/domain/`, заголовки в `include/mru/domain/`.
- `debounce_ms` кламп **[0,5000]**; `start_offset` default `second`; `wrap` default `true`; `restore_focus_on_cancel` default `false`; `default_scope` default `Global` (SPEC §4, REQ-CFG-004).
- `start_offset=second` → `initial_index = min(1, len-1)`; `first` → 0 (REQ-SEL-001/002).
- Коллекция Selection — `size_t index` в пределах snapshot (инвариант ARCHITECTURE §4.2.2).
- Cycle **никогда не фокусирует** (REQ-F-003); apply — **максимум один focus** (REQ-F-006) и ровно одно UI `on_session_end` (REQ-F-007).
- Snapshot иммутабелен в течение сессии кроме prune (REQ-SNAP-003).
- Lock-in: при Active focus для истории игнорируется (REQ-H-001).
- `apply` при пустом после prune → `{ok:false, error:"no windows"}` (REQ-DISP-002, FM-01/02).
- Приоритет: SPEC → ADR → это план.

```cpp
// snapshot.hpp
class Snapshot {
public:
  Snapshot(std::vector<WindowRef> windows, Scope scope);
  const std::vector<WindowRef>& windows() const;
  std::size_t size() const;
  bool empty() const;
  const WindowRef& at(std::size_t i) const;   // pre: i < size()
  Scope scope() const;
private: std::vector<WindowRef> windows_; Scope scope_; };

// window_source.hpp
class WindowSource {
public:
  virtual ~WindowSource() = default;
  virtual std::vector<WindowRef> candidates(Scope scope) const = 0; // упорядочены MRU-first
  virtual bool is_valid(const WindowRef& ref) const = 0;            // address AND generation (REQ-F-005)
  virtual std::optional<WindowRef> focused() const = 0;             // текущий фокус, если известен (REQ-S-007)
};

// focus_gateway.hpp
enum class FocusResult { Applied, InvalidTarget, Failed }; // REQ-F-008
class FocusGateway {
public:
  virtual ~FocusGateway() = default;
  virtual FocusResult focus(const WindowRef& ref) = 0;   // ровно один вызов на apply-success
};

// ui_port.hpp
enum class UIEndReason { Applied, Cancelled };           // coarse UI reason (REQ-F-007/009)
class UIPort {
public:
  virtual ~UIPort() = default;
  virtual void on_session_start(const Snapshot& snapshot, std::size_t index) = 0;
  virtual void on_selection_changed(std::size_t index) = 0;
  virtual void on_session_end(UIEndReason reason) = 0;
};
```

```cpp
  void on_window_invalid(const WindowRef& ref); // prune active snapshot при window.close (FM-04)
  bool is_active() const;
  std::uint64_t session_id() const;           // монотонно растёт за время жизни (REQ-S-008)
  const std::optional<Snapshot>& active_snapshot() const;
  std::size_t index() const;
  const std::optional<WindowRef>& session_origin() const;
private:
  CommandResult begin_session(Scope scope);
  CommandResult end_session(SessionEndReason reason, std::string_view error);
  std::optional<WindowRef> resolve_and_focus();
  void prune_active();
  // поля: WindowSource& source_; FocusGateway& fg_; UIPort& ui_; HistoryTracker& tracker_;
  // SessionPolicy policy_; SessionPolicy snapshot_policy_; bool active_=false; std::optional<Snapshot> snapshot_;
  // std::size_t index_=0; std::optional<WindowRef> session_origin_; std::uint64_t session_id_=0;
};
```

**Поведение (нормативно, SPEC §2.1–2.8 + TRANSITION-TABLE):**

`cycle(dir, override)`:
```
if !active_:
    scope = override иначе policy_.default_scope
    candidates = source_.candidates(scope)
    if empty: return {false, "no windows"}            // REQ-S-002 guard, T-S-04
    snapshot_ = Snapshot{candidates, scope}           // REQ-SNAP-001 (MRU-first от source)
    index_ = initial_index(policy_.start_offset, size) // REQ-SEL-001/002
    session_origin_ = source_.focused()               // REQ-S-007
    ++session_id_                                      // REQ-S-008
    snapshot_policy_ = policy_                        // REQ-S-009 (snapshot политики; reload не меняет mid-session)
    if policy_.lock_history_on_session: tracker_.set_session_locked(true)  // lock-in
    active_ = true; ui_.on_session_start(*snapshot_, index_)
    return {true, ""}
else:
    // REQ-S-010: scope override при Active игнорируется БЕЗ rebuild, но selection
    // продолжает двигаться (SPEC wins — поправлено при интеграции, T-S-07).
    index_ = advance_index(index_, dir, snapshot_policy_.wrap, size)   // REQ-SEL-003/004/005
    ui_.on_selection_changed(index_)
    return {true, ""}
```

`apply()` (ADR-014, design-notes/apply-after-invalidation):
```
if !active_: return {true, ""}                       // идемпотент, FM-12
prune_active()
if !snapshot_ || snapshot_.empty():
    return end_session(NoWindows, "no windows")       // exact message, REQ-DISP-002, FM-01/02
// clamp уже выполнен в prune_active; повторная проверка (SPEC §2.8 шаг 3):
if !source_.is_valid(snapshot_.at(index_)):
    prune_active(); if empty -> end_session(NoWindows, "no windows")
index_ = min(index_, size-1)
result = fg_.focus(snapshot_.at(index_))              // РОВНО ОДИН focus (REQ-F-006)
switch(result):
  Applied          -> return end_session(Applied, ?)      // {true,""}
  InvalidTarget    -> return end_session(InvalidSelection, "no windows")
  Failed           -> return end_session(FocusFailed, "no windows")  // + warn log hook, FM-10
```

`cancel()` (REQ-S-005, REQ-R-001/002):
```
if !active_: return {true, ""}                        // идемпотент, FM-13
auto origin = session_origin_
end_session(UserCancel, "")                           // ui_.on_session_end(Cancelled), unlock
if snapshot_policy_.restore_focus_on_cancel && origin && source_.is_valid(*origin):
    fg_.focus(*origin)                                 // REQ-R-001; невалидный -> no-op REQ-R-002, T-S-06
return {true, ""}
```

`end_session(reason, error)`:
```
active_ = false; snapshot_.reset(); index_ = 0
if lock_history_on_session (по snapshot_policy_): tracker_.set_session_locked(false)
ui_.on_session_end(reason==Applied ? UIEndReason::Applied : UIEndReason::Cancelled)  // REQ-F-007, только если была сессия
return CommandResult{ ok: reason==Applied, error }
```

`prune_active()`: удалить из `snapshot_` все `!source_.is_valid(ref)` (стабильный порядок), `index_ = min(index_, size-1)`; если пусто — снять сессию (Cancelled).

`on_focus(ref)`: `if active_ -> return;` else `tracker_.on_focus(ref)` (REQ-RE-003, lock-in через set_session_locked; T-RE-01).

`on_window_invalid(ref)`: если `active_` и ref в snapshot_ — `prune_active()`; пусто → завершить (NoWindows→Cancelled). Иначе `tracker` не трогает (его задача — T-H-05 через Validator).

**General rules:** никакого focus из cycle (REQ-F-003); никаких исключений наружу — деspatch-обёртка позже (REQ-ERR-001, M2).
